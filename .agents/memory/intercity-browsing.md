description: User-defined browsing model for intercity buses within Transtop.

Use a transit option labeled “Intercity Bus Network” alongside existing modes, not a separate Port Authority hub. Filter stops and available providers by the user's selected location; after choosing a provider, show upcoming departures and each trip's subsequent stops and final destination.

**Why:** The user explicitly rejected the separate Port Authority hub approach in favor of seamless integration with MTA buses, trains and commuter rail.

**How to apply:** Treat Port Authority as a boarding location within shared nearby, map and timetable experiences. The supplied carrier list guides initial source coverage, not a terminal-specific navigation structure.
